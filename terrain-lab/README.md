# Terrain Lab

An interactive 3D terrain generator for the Computer Graphics course.

## Goal
Create mountains and valleys using procedural generation,
with interactive controls, lighting, terrain colors, and water.

## Development Plan
1. Set up a runnable application.
2. Create a flat triangle grid.
3. Generate a mathematical hill.
4. Add procedural noise and a reproducible seed.
5. Add terrain controls.
6. Calculate normals and add lighting.
7. Add terrain colors and adjustable water.
8. Complete camera controls and documentation.

## Workflow
Implement and verify one small task at a time.
Commit each completed task separately.

## Current Status
Project planning. Terrain implementation has not started.
